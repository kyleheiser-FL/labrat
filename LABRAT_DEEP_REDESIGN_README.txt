This package is a deeper visual redesign pass built from the merged LabRat app state.

It keeps the current app logic and changes the page/product presentation more deeply than the earlier hero-only pass.

Key changes:
- Shop product cards are redesigned below the hero, not just the top page hero.
- Shop vials are enlarged and staged as premium LabRat-branded vial cards.
- Product cards include Norway Peptides QA / COA batch trace / LabRat vial label strips.
- Buy bars, strength selector panels, and cart rows get mockup-style command card treatment.
- Clinical Dark is made more distinct from Neon with reduced glow, slate/blue controls, and cleaner product cards.
- Existing shop products, IDs, prices, inventory, cart/order logic, Firebase, auth, PWA files, and bloodwork logic are not intentionally changed.
