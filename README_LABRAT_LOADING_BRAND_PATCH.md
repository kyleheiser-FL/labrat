# LabRat Loading Brand Patch

Replaces the old temporary loading screen with a LabRat-branded LR loader.

- Clinical/default: clinical LR icon + clean OLED black styling.
- Neon: neon LR icon + cyan/green glow if the saved theme is neon.
- Includes PWA icon assets used by the loader.
- Does not modify Firebase, cycle data, compounds, shop logic, PWA registration, or service worker behavior beyond optional caching of these loader icons.
